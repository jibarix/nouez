# Rules

Every rule nouez applies, in one place. **Code** means nouez's code holds to the rule: a tool refuses, changes or leaves out something. **Instructions** means nouez only tells Claude, in its server instructions, a tool description or a result, and Claude follows them or not. The last column names the test in `tests/test_protocol.py` that covers the rule (`test_` left out), or says there is none. The “For example” column shows each rule as a user meets it.

A change to one of these rules changes this page in the same commit ([REVIEW.md](../REVIEW.md) item 16). `verify.py` checks that the page names every setting nouez reads and only tests that exist; whether a row is missing, or a test checks what its row says, is for the review.
